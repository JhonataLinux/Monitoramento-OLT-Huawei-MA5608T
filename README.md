# Huawei MA5608T Monitoring — Zabbix + Grafana

Dashboard de monitoramento para OLT Huawei MA5608T utilizando
Zabbix, SNMP e Grafana.

## Monitoramento

- CPU por placa
- Temperatura da OLT
- Temperatura dos FANs
- Rotação dos FANs
- Uptime
- Status dos uplinks
- ONUs online
- ONUs offline
- ONUs autorizadas
- Status das interfaces GPON
- Bits In / Bits Out
- TX Power
- Bias
- Laser
- Temperatura
- Voltagem

## Stack

- Zabbix 7
- Grafana
- SNMP v2c
- Huawei MA5608T
- Linux
